What a skill file is, and how to add one to Claude

So what is a skill file?

Think of it like a recipe card for Claude. It's a small file of written steps that tells Claude exactly how to do one kind of task the same good way every time. You add it once, and after that you just ask for the task in plain words. Claude notices the skill fits and follows it.

No coding. You don't have to open the file or understand what's inside it. You just upload it.

What you need

  • A paid Claude plan: Pro, Max, Team or Enterprise. Skills don't work on the free plan.
  • Claude on the web (claude.ai) or the Claude desktop app.
  • The skill files. These come as .zip files, so leave them zipped. Claude wants the .zip itself.

How to add a skill to Claude

  1. Open Claude and go to Settings, then Capabilities.
  2. Make sure Code execution and file creation is turned on. Skills need it to run.
  3. Scroll down to the Skills section and click Upload skill.
  4. Pick one of the .zip files you downloaded. Do one file at a time.
  5. Make sure the new skill's toggle is on. That's it, it's installed.
Heads up

On a Team or Enterprise plan, your company's admin may need to turn skills on first. If you don't see the Skills section, ask them.

How to use a skill once it's added

Just ask for the task like you'd ask a friend. For example, "map my career goals" or "update my resume." Claude picks the right skill on its own. If it ever doesn't, say the skill's name: "use the resume builder skill."

My tip: make a Claude Project for each big goal (like "Job Search") and do all the related chats inside it. Some skills save notes there, so the next skill can pick up where the last one left off.

The fine print

  • These skills are free for your own personal use.
  • I don't offer one on one setup help for the free skills. The guides and videos should cover everything.
  • When I improve a skill, I'll email the new version to the list. Just upload the new .zip over the old one.
  • Claude can still make mistakes, so always read what it makes before you send it or post it.
